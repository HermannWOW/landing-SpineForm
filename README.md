# SpineForm

O **SpineForm** é uma ficha de avaliação clínica online desenvolvida para fisioterapeutas que trabalham com coluna e desejam tornar seus atendimentos mais práticos, organizados e profissionais.

Com uma interface moderna e fácil de usar, o SpineForm permite preencher toda a avaliação diretamente pelo navegador, incluindo informações do paciente, escalas clínicas, questionários e um mapa corporal interativo para identificação dos sintomas. Ao final, é possível gerar um PDF com os dados preenchidos de forma organizada.

A proposta do SpineForm é substituir fichas tradicionais e processos manuais por uma experiência digital mais simples, visual e eficiente, que pode ser utilizada em computador, tablet, iPad ou celular, sem necessidade de instalação.

O foco é ajudar o profissional a ganhar agilidade durante a avaliação, manter as informações bem estruturadas e entregar um atendimento com uma experiência mais moderna e profissional.
